# «СЛОво» для собственного сервера

Android «СЛОво» — пример клиента для самостоятельно развёрнутого бэкенда. Публикация проекта не предоставляет доступ к серверу автора.

## Статус APK

APK 1.8.10 временно снят с публичной загрузки. Статическая проверка выявила встроенный прежний сервер: он используется при отсутствии сохранённого адреса и при пустом значении. Поэтому эту сборку нельзя представлять как пример с обязательным вводом собственного сервера.

Для публикации готовится отдельный пример с обязательным вводом собственного сервера. Он будет иметь отдельный пакет и подпись и не является обновлением установленного приложения.

## Настройка уже имеющегося клиента

1. Разверните этот бэкенд на своём сервере и настройте HTTPS для собственного домена.
2. Откройте настройки «СЛОво».
3. В поле «Адрес Lampac» укажите HTTPS-адрес своего бэкенда, например `https://example.invalid`, заменив пример собственным доменом.
4. Нажмите «Сохранить», затем «Проверить». Приложение должно показать «Соединение установлено».

Название поля относится к прежнему серверу; оно принимает адрес самостоятельного бэкенда. Не оставляйте поле пустым в старых сборках с заданным сервером по умолчанию.
