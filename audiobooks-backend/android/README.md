# «СЛОво» — пример для своего сервера

[Скачать APK-пример](https://raw.githubusercontent.com/ARST113/log/main/audiobooks-backend/android/slovo-own-server-example-1.8.10.apk)

Это отдельная сборка на основе «СЛОво» 1.8.10 с обязательной настройкой собственного сервера. Публикация проекта не предоставляет доступ к серверу автора. Требуется Android 6.0 или новее.

Пакет `app.lampac.slovo.example`, версия `1.8.10-own-server-example`, код версии 24. Используется отдельная подпись: пример устанавливается рядом с исходным «СЛОво» и не является его обновлением. Данные исходного приложения не переносятся.

## Настройка

1. Разверните этот бэкенд на своём сервере и настройте HTTPS для собственного домена.
2. Установите APK-пример. Android может попросить разрешить установку из браузера или файлового менеджера.
3. При первом запуске введите HTTPS-адрес своего сервера. Поле изначально пустое; адрес сервера по умолчанию отсутствует.
4. Введите ключ доступа своего бэкенда, если он защищён ключом. Поле ключа изначально пустое и скрывает введённые символы.
5. Нажмите «Сохранить и открыть „СЛОво“». До сохранения корректного адреса каталог не запускается.

Ключ передаётся через защищённый префикс `/access/<ключ>` адреса API, совместимый с этим бэкендом. Для HTTPS-адресов с таким префиксом автоматические HTTP-варианты аудио и обложек отключены; переход по HTTP `Location` с префиксом доступа также запрещён. После настройки сохраняется интерфейс «СЛОво», включая поиск, воспроизведение, историю и загрузки. Изменить адрес можно в его настройках, в поле «Адрес Lampac»; при необходимости укажите защищённый адрес собственного сервера с префиксом доступа.

## Контрольная сумма и подпись

SHA-256 APK:

```text
861894bea210282995b439960b2b6c0cdee51ae635e97767331ae536b53188ca
```

SHA-256 сертификата отдельного примера:

```text
ba252e391c453e0c861e6b396e03187efae2d42dcdf426ed80b74ec98a0c4404
```

Подписи APK v1/v2/v3 и выравнивание проверены. Проверка всех записей APK подтвердила отсутствие личных серверных адресов. Прежняя неизменённая сборка снята с актуальной публикации, поскольку содержала встроенный сервер по умолчанию и DNS fallback.

На Android проверены пустая первоначальная настройка, отказ сохранять пустой адрес, ввод своего сервера и ключа, каталог, обложки, поиск, карточка книги, воспроизведение и пауза. Патчер и статический тест транспорта приложены отдельно.
