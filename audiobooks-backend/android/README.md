# «СЛОво» для Android

[Скачать slovo-1.8.10.apk](https://raw.githubusercontent.com/ARST113/log/main/audiobooks-backend/android/slovo-1.8.10.apk)

Версия 1.8.10, код версии 23, пакет `app.lampac.slovo`. Требуется Android 6.0 (API 23) или новее. APK совпадает с установленной сборкой, на которой проверены поиск и воспроизведение с самостоятельным бэкендом.

1. Установите APK. Android может попросить разрешить установку из используемого браузера или файлового менеджера.
2. Откройте настройки «СЛОво».
3. В поле «Адрес Lampac» укажите `https://knigaslovo.duckdns.org` либо HTTPS-адрес своего бэкенда.
4. Нажмите «Сохранить», затем «Проверить». Приложение должно показать «Соединение установлено».

Название поля относится к прежнему серверу; оно принимает адрес самостоятельного бэкенда. APK сохранён без перепаковки и изменения подписи. Адрес нового сервера нужно указать в настройках; эта сборка не содержит его в качестве нового значения по умолчанию.
